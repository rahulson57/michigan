# Contributing

Thanks for your interest in contributing! Here's how to get started:

1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork locally and create a new branch for your change:
   ```sh
   git checkout -b my-feature-branch
   ```
3. Make your changes, committing with clear, descriptive messages.
4. Push your branch to your fork:
   ```sh
   git push origin my-feature-branch
   ```
5. Open a **pull request** against the `main` branch, describing what you changed and why.

Please keep pull requests focused and small where possible, and be responsive to review feedback. Thanks for contributing!
